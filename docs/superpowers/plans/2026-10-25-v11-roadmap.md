# Seafarer Budget 1.1 — дорожная карта сборки

> **For agentic workers:** this file is the index. Each stage has its own plan (`2026-10-25-v11-stage*.md`), written right before the stage starts, from the code the previous stage produced. Execute plans with superpowers:subagent-driven-development or superpowers:executing-plans.

**Goal:** выпустить 1.1.0 (телефон, ПК, бот, база) одним выпуском по спецификации.

**Spec:** `docs/superpowers/specs/2026-10-22-redesign-daily-budget-design.md` (утверждена 2026-10-25). Макет с итоговым интерфейсом (эталон для этапов 2–3): `seafarer-budget-preview.html`, опубликован https://claude.ai/artifact/LqtPifsFHbs7Tutu6JFTFK (версия 60).

## Правила на всю сборку

- Работа — в ветке `v1.1` (создаётся в начале этапа 0 от `main`). Ничего не пушится и не деплоится до этапа 7; живые бот и приложение 1.0 не трогаются.
- Секреты — только в `budget/.env` и `budget/bot.env`, используются через `node --env-file=…` / `supabase secrets set --env-file`, значения никогда не печатаются и не попадают в репозиторий и в чат. Chat id Маши — только в `bot.env`.
- Каждый этап заканчивается зелёными `npm test` и `npx tsc --noEmit`, коммиты маленькие, по задачам.
- Если реализация расходится со спецификацией (найдена ошибка или противоречие), спецификация правится тем же коммитом, с пометкой даты.

- **Этап 2 (остатки итоговой проверки, 2026-10-25):** `Home.tsx` меняет дату посадки через весь объект настроек (`{...settings, next_contract_date}`) — слать только `{id, next_contract_date}`, иначе устаревший снимок попадёт в `_changed`. ### Отступления от плана и решения по ходу

- Порядок задач: 1–12, затем 14, 13, 15 — удаление данных (13) открывает мастер в режиме «только Остаток», который сделан в 14.
- Пока экраны 1.0 не были заменены, их показывали как есть (значок синхронизации, временные «Скоро» для категорий и архива, старое управление категориями и счетами) — к концу этапа всё старое удалено вместе с `styles.css` 1.0.
- Навигация: нижние экраны стека остаются смонтированными (скрыты, `inert`), при свайпе назад показывается тот же элемент, прокрутка восстанавливается для каждого; каждый экран читает свой маршрут (`useRoute`).
- Кривая перестановки (flip) — `--ios`, как в спецификации (в макете другая). Возврат шторки и закрытие — без отскока (damping 1).
- Шторка записи даёт «Удалить» и «В архив» и без жестов. Пока идёт сохранение, шторку не закрыть (фон, Esc, потянуть). Категория из корзины показывается приглушённой выбранной плашкой. В списке счетов — «≈ $остаток».
- «Укажи дату посадки» на главной сохраняет дату на месте и даёт ссылку в «Ещё» за запасом (§2 «→ настройки» выполнено ссылкой).
- Потянуть главную вниз: страница не пружинит (`overscroll-behavior-y: none`), жест берётся с первого движения вниз у верха страницы; слушатели жестов шторки и обновления ставятся сразу при отрисовке (layout effect), чтобы касание сразу после появления экрана не терялось.
- «Самая крупная трата» в отчёте может открыть архивную запись (отчёты считают архив, §4); фильтр «Маша» из отчёта переходит в «Расходы».
- Цели: «Забрать» не больше отложенного; суммы целей — целыми долларами (как в макете); срок новой цели — не раньше завтра.
- «Сверка» показывает основную валюту и валюты с ненулевым остатком, кнопка серая (лайм — только главное).
- Категории: переименование из 1.0 сохранено — смахивание «Изменить · В архив · Удалить» открывает форму категории (строка добавлена в §4). **Сказать Кириллу** — возможно, он захочет другой вход.
- Удаление категории запоминает перенесённые записи в локальной `meta` Dexie: «Отменить» — действие тоста на этом же устройстве.
- Удаление счёта на сервере окончательное: архив прячет счёт сразу, а удаление пишется, когда тост «Отменить» истёк (если приложение закрыли раньше — счёт остаётся); перед записью счёт проверяется заново.
- «Начальный остаток» датируется вчерашним днём (`initDefaults`, `addOpening`), иначе `dailyBudget` откатывает его в первый день (заметка в §2).
- «Вернуть удалённое» после «Удалить все данные» и мастера убирает в корзину новый «Начальный остаток» (иначе остаток двоится; заметка в §4).
- `styles.css` сведён к базе по макету: `.card`, `.label` (серая подпись 13 px — без заглавных букв 1.0), `.muted` и т. п.; формы (`.rec`, `.btn-acc`, `.btn-tint`, `.textbtn`, `.reveal`) — в `ui/ui.css`; общие функции вынесены из экранов (`ui/useDayTick.ts`, `ui/keys.ts`, `lib/records.ts`, `useSlideIn`).
