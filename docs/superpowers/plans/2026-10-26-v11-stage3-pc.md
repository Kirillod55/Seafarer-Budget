# Этап 3 — ПК (широкое окно ≥ 1024 px)

> Исполнять задача за задачей (TDD, маленькие коммиты, после каждой `npm test` + `npx tsc --noEmit`). Журнал — `v11-stage3-progress.md` (строка на задачу с коммитом). Телефонная раскладка (< 1024 px) не меняется: все существующие тесты остаются зелёными.

**Спецификация:** §11 целиком; §4 (мастер, «Параметры → Данные»), §6 (стекла на ПК нет). **Эталон:** `docs/design/prototype-v60.html` (`html.desk`, `html.desk-s`, `.side`, `.dhead`, `.dtable`, `.srow`, `.syncfly`, `.au-*`).

**Принцип:** одна кодовая база. Раскладку выбирает ширина окна: классы `desk` (≥ 1024) и `desk-s` (1024–1279) на `<html>`; почти весь вид ПК — CSS под `html.desk` в `src/desk/desk.css`. Компоненты ветвятся по `useLayout()` только там, где другая разметка (меню, шапка, таблицы, обзор, вход/мастер).

## Задачи

1. **Раскладка по ширине.** `src/desk/layout.ts`: `layoutFor(width): 'phone' | 'icons' | 'full'`, `applyLayout(mode, doc)` (классы `desk`/`desk-s`), `watchLayout(win)` (matchMedia 1024/1280, сразу при изменении), `useLayout()` (useSyncExternalStore). Вызов в `main.tsx` до первой отрисовки. Тесты `desk/layout.test.ts`: «1023 → phone, 1024 → icons, 1280 → full», «classes follow the media queries», «phone removes both classes».
2. **Меню слева + смена раздела.** `src/desk/Sidebar.tsx` (якорь, «Seafarer Budget», 7 пунктов, разделитель, «Настройки»; внизу статус Маши `partner_seen_at` → «Маша подключена к боту» / красное «… не подключена к боту», клик → «Настройки»; подсказка клавиш). `Navigator`: `open(route)` — стек из одного экрана, переход `desk`; на ПК вместо `.tabs` — `Sidebar`; `activeItem(route)` (календарь → Главная, «Расходы» из категорий → Категории, из отчёта → Отчёт). Любая смена раздела — `.v-desk` (0.28 с). Тесты `desk/Sidebar.test.tsx`: «items open their screens», «calendar keeps Главная current», «partner status: linked / not linked», «phone shows tabs, not the sidebar».
3. **Шапка страницы.** `NavBar` на ПК — `.dhead`: заголовок 28 px слева, действия справа (кнопки Windows `.fbtn`), «‹ Ещё» скрыта, «‹ Главная/Отчёт/Категории» — путь-крошка. Тест в `nav/nav.test.tsx`: «desk header hides «‹ Ещё» and keeps «‹ Категории»».
4. **Вид Windows 11 (CSS).** `src/desk/desk.css`: плотнее (14 px, радиусы 8/6, поля 36, фокус полоской снизу), без стекла (`.glass`, тосты, пилюли — плотные поверхности, `--fly-shadow`), тонкая полоса прокрутки, тост справа внизу, ширины колонок (1120 / 780 / 960 / 1240), цели в две колонки, отчёт `.rgrid`, счета сеткой + «Операции» справа и прилипают. Без тестов (CSS); проверка глазами в демо.
5. **Окно записи по центру + ловушка фокуса.** `Sheet`: на ПК — диалог 560 px по центру (CSS), без перетаскивания, закрытие 0.14 с; ловушка Tab внутри окна (телефон тоже), `inert` на `#root` под окном. Фокус после закрытия — на прежний элемент, иначе на «Новая запись». Тесты `ui/ui.test.tsx`: «Tab cycles inside the sheet», «the app under the sheet is inert while open», «desk: no drag, closes in 140 ms».
6. **Строки: наведение и правая кнопка.** `SwipeRow` на ПК: без смахивания, кнопки `.hov` (Изменить · В архив · Удалить) на месте суммы; `onContextMenu` → `src/desk/ContextMenu.tsx` (стрелки, Esc, клик мимо). `TxRow` добавляет «Дублировать на сегодня» (копия с сегодняшней датой и «Отменить»). Тесты `desk/rows.test.tsx`: «hover buttons archive/delete with undo», «context menu: duplicate for today + undo», «Esc and click outside close the menu», «phone rows still swipe» (существующие).
7. **Клавиши.** `src/desk/useDeskKeys.ts` в `Shell` (только ПК): `N` новая запись, `/` быстрая строка (с переходом на главную), `↑` `↓` по строкам `.tx` на экране, `Enter` открыть, `Delete`/`Backspace` удалить с «Отменить», `Esc` закрыть меню/окно; не срабатывают в полях и под открытым окном. «Enter в сумме сохраняет» — проверить в `RecordSheet`. Тесты `desk/keys.test.tsx`: «N opens a new record repeatedly (after Отмена, Esc, Готово)», «N → 45 → Enter saves and focus returns to Новая запись», «keys are ignored in inputs», «↑↓ move, Delete removes with undo», «/ focuses the quick input from another section».
8. **Главная — панель.** `src/desk/Overview.tsx`: календарь месяца (подсветка лаймом по сумме, сегодня обведено, будущее бледное, клик → календарь на день), месяц (сумма, «Я / Маша», топ-4 категорий, «Отчёт ›»), цели, лимиты (жёлтая/красная полоска). `Home` на ПК — `.dgrid` (основная колонка + обзор, прилипает), «＋ Новая запись `N`». `Calendar` принимает день из маршрута (`day?`). Тесты `desk/Overview.test.tsx`: «day sums match the calendar», «top-4 and me/partner match the report», «click on a day opens the calendar on it», «limit bar warn/over».
9. **Облачко-кнопка.** `SyncCloud` на ПК — кнопка с панелью `.syncfly` (состояние, время, «Синхронизировать сейчас» → «Синхронизирую…», тост «Синхронизировано»); закрытие повторным кликом, кликом мимо, `Esc` (фокус на облачко), сменой раздела. Тесты в `components/SyncCloud.test.tsx`: «desk: flyout opens, syncs, closes on Esc».
10. **Таблицы.** `Categories` (две таблицы: категория, записей, за месяц, лимит; клик/Enter → траты категории; наведение «В архив»/«Удалить»), `Archive` (название, тип, подробности, «Вернуть»/«Удалить» с подтверждением строкой), `Limits` (категория, потрачено, лимит, осталось, полоска, статус, «Убрать»; новый лимит — карточкой над таблицей). Тесты в существующих `*.test.tsx` под `desk`: «desk renders a table with the same rows and actions».
11. **Настройки.** `More` на ПК — «Настройки»: ссылки Лимиты/Счета/Категории/Архив скрыты, карточки — группы «Параметров» (CSS `.mcard` → группа строк), строка «О программе»: версия и «Проверить обновления» (только Tauri). Тест в `More.test.tsx`: «desk: titled Настройки, no menu links, about row».
12. **Вход и мастер в две панели.** `src/desk/AuthBrand.tsx` (якорь, имя, слоган, «Версия 1.1 · для Windows», отсвет). `Login` на ПК: три пункта слева, форма 400 px (Email, Пароль с глазом, «Оставаться в системе», «Забыли пароль?», «Войти»; фокус в Email, Enter входит). `Wizard` на ПК: шаги слева как у установщика, справа «Шаг N из 3», полоса кнопок внизу. Тесты в `Login.test.tsx`, `Wizard.test.tsx`: «desk: two panes, eye toggles password», «desk: steps list marks current/done».
13. **Окно Windows и автообновление.** `tauri.conf.json`: `minWidth 400`, `minHeight 640`, версия 1.1.0, `plugins.updater` (`endpoints` = `https://github.com/Kirillod55/Seafarer-Budget/releases/latest/download/latest.json`, `pubkey` = заглушка `REPLACE_AT_RELEASE_STAGE7`), `bundle.createUpdaterArtifacts: true`; `Cargo.toml` — `tauri-plugin-updater`, `tauri-plugin-process`; `main.rs` — плагины; `capabilities/default.json` — `updater:default`, `process:allow-restart`. JS: `src/desk/updater.ts` (`checkForUpdate` при запуске и раз в 6 ч, молча без сети; `install` с прогрессом, ошибка → «Не удалось обновить, попробую позже») и `UpdateToast` справа внизу («Доступна версия X · Что нового · Обновить и перезапустить · Позже»). Плагины грузятся `import()` только в Tauri. Тесты `desk/updater.test.ts`: «offline check is silent», «newer version shows the toast», «Позже hides until next start», «install reports progress / failure». Шаг ключей описан в `docs/release/tauri-updater.md` (`npx tauri signer generate`, открытый ключ → `tauri.conf.json`, закрытый и пароль → секреты GitHub; ключи создаются на этапе 7, закрытый ключ никогда не коммитится).
14. **Доводка из этапа 2.** Onest: свои `@font-face` только latin + cyrillic (`src/ui/fonts.css`, файлы из `@fontsource-variable/onest`) вместо всех 7 наборов. Разделить сборку: редкие экраны (`Report`, `Accounts`, `Wizard`, ПК-модули) — `React.lazy`/`import()`, вендоры отдельным чанком; главный JS < 500 kB. Тест `index-html.test.ts`/`fonts.test.ts`: «only latin and cyrillic faces».
15. **Проверка и итог.** Демо `#demo` при 1024 / 1280 / 1440 в обеих темах (меню, обзор, таблицы, окно записи, клавиши), `scripts/check-layout.mjs` для 375 px без изменений. Самопроверка всего диффа, `npx vite build`, `npm audit --omit=dev`, итог этапа в дорожной карте.
