# Seafarer Budget 1.1 — этап 2: приложение на телефоне — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** перевести всё приложение (ширина < 1024 px) на дизайн 1.1 из утверждённого макета: дизайн-система «графит и лайм», 4 вкладки, шторка записи, жесты и анимации, главная с бюджетом на день, календарь, отчёт и «Расходы», цели, «Ещё» с настройками, категории, архив, удаление и загрузка данных, Маша, счета, лимиты, вход и мастер.

**Architecture:** React-экраны остаются в `src/screens/`, но строятся из новых общих деталей `src/ui/` (токены, переключатели, меню, шторка, строки со смахиванием, уведомления, плавная перерисовка) и нового навигатора `src/nav/` (стек экранов внутри 4 вкладок). Данные и расчёты — готовые функции этапа 1 (`dailyBudget`, `reservingGoalMoves`, `repo.remove/restore/wipe/wipeAll/importRows/setArchived`, `parseCsv/planImport`, `money`). Для проверки глазами — режим «демо» только в dev-сборке (`#demo`): своя база Dexie с примерами, без Supabase.

**Tech Stack:** React 19, TypeScript 7, Vite 8, Dexie 4 + `dexie-react-hooks`, Vitest 5 + Testing Library (jsdom), новые зависимости: `@fontsource-variable/onest`, `lucide-react`; `recharts` удаляется (кольцо — своё SVG).

**Spec:** `docs/superpowers/specs/2026-10-22-redesign-daily-budget-design.md` — разделы 2, 3, 4, 6, 9 «Приложение». **Эталон вида и поведения:** `docs/design/prototype-v60.html` (макет v60, опубликован https://claude.ai/artifact/LqtPifsFHbs7Tutu6JFTFK) — в задачах указаны функции макета (`home()`, `recordSheet()`…), CSS-правила там же. Где макет и спецификация расходятся — права спецификация. Дорожная карта и перенесённые пункты: `docs/superpowers/plans/2026-10-25-v11-roadmap.md`.

## Global Constraints

- Ветка `v1.1`; ничего не пушить и не деплоить; секреты `.env`/`bot.env` не читать.
- Этот этап — только телефонная раскладка (ширина < 1024 px). ПК — этап 3; не закладывать в экраны то, что мешает добавить там меню слева и окно записи по центру (раскладка через классы на `<html>`, без жёстких `max-width: 430px` в компонентах).
- Токены (§6), тёмная / светлая: `--bg` `#0E0F12`/`#FFFFFF`, `--card` `#181A1F`/`#FFFFFF`, `--line` `#262930`/`#E8E8EC`, `--text` `#F2F3F5`/`#14161A`, `--muted` `#8E939C`/`#6B6B73`, `--accent` `#C6F432`, `--on-accent` `#11140A`, `--accent-text` `#C6F432`/`#4D6B00`, `--warn` `#FF8A5B`/`#C2410C`, `--danger` `#FF5C5C`/`#D70015`, `--track` `#262930`/`#F2F2F5`, `--anchor` `#5B9BFF`/`#1D4ED8`, `--partner` `#E4E6EA`/`#3A3D44`, `--act-edit` `#55585F`/`#8E8E93`, `--act-del` `#FF453A`/`#FF3B30`, `--act-arch` `#C77700`/`#FF9500`, `--pill-warn` `#F5B83D`/`#9A6200`. Стекло — сплошное: меню `#24272D`/`#FFFFFF`, плашка «Отменить» `#2A2D33`/`#FFFFFF`, кнопки-пилюли `#1F2126`/`#F2F2F5`, вкладки и шапка `#0E0F12`/`#FFFFFF`; без `backdrop-filter`, без полупрозрачных бликов и затуханий. Ни одного жёстко заданного цвета фона в компонентах — только токены.
- Тема: `data-theme` на `<html>` (`light`/`dark`), «Как в системе» = без атрибута + `prefers-color-scheme`; правила явной темы специфичнее `@media` (тест обязателен); выбор хранится локально в `meta` Dexie (`key: 'theme'`), не синхронизируется; `<meta name="theme-color">` = `--bg` текущей темы. Смена темы — плавный перелив цветов 0.4 s без перезагрузки экрана. «Увеличение контраста» (`prefers-contrast: more`): чёткие границы цвета текста у карточек, полей и кнопок, приглушённые подписи становятся полноцветными.
- Шрифт Onest (variable, `@fontsource-variable/onest`, офлайн), цифры `font-variant-numeric: tabular-nums`. Размеры: основной 17, вторичный 14–15, подписи 13, поля 17; размеры в `rem` от `-apple-system-body` (Dynamic Type), коэффициент 1–1.3 — раскладка не ломается при 1.2.
- Формы телефона: карточки и группы радиус 20, поля 12, кнопки 14; кнопки-пилюли 34 px высотой, круглые 36 px; цели касания ≥ 44 px.
- Кривые: `--ios: cubic-bezier(.32,.72,0,1)`, `--spring: cubic-bezier(.34,1.45,.64,1)`; жесты на пружинах со скоростью пальца (затухание/отклик Apple, проекция 0.998, у строк 0.99); всё отключается при `prefers-reduced-motion`.
- Суммы — только через `money()` (`$4,963.32`, `₴1,200`, `MDL 90`); расходы без «−», доходы зелёным с «+».
- Подписи с большой буквы («Свободно», «Запас», «Посадка», «Потрачено сегодня», «Бюджет на день», «Осталось $X» / «Перерасход $X», «В норме», «Почти всё», «Превышен», «Подключена»); заметка траты показывается с заглавной буквы.
- Удалённое: списки показывают только `alive()` и не `archived` (архивные траты скрыты, но считаются в балансе, бюджете дня и отчётах). Все удаления — мягкие с «Отменить» (`repo.remove` → batch → `repo.restore`).
- Настройки менять только через `repo.put('settings', { id, ...изменённые поля })` — не весь объект (иначе устаревший снимок попадёт в `_changed`).
- Новые строки ставят автора и прочие поля 1.1 явно: записи `author` (из «Чья трата»), `archived: false`; движения целей `author: 'owner'`, `source: 'app'`, `created_at` = сейчас.
- Лайм только для главного (§6): «＋», выбранное, «Бюджет на день», «Осталось», облачко, главная кнопка экрана, «В архив» в целях; «назад», листание месяцев и дата — цвет текста.
- Ничего не выходит за край и не обрезается на ширине 375 px в обеих темах (проверка в демо-режиме, Задача 15).

## Review Focus

1. **Клавиатура iPhone и шторка** — поле суммы в шторке не уходит под клавиатуру, страница не увеличивается при фокусе (шрифт полей 17 px), прокрутка под шторкой закреплена и возвращается на место после закрытия. Тест: Задача 5 (scroll lock восстанавливает позицию; `font-size` полей ≥ 17 px в CSS-тесте).
2. **Очень длинные значения на 375 px** — сумма `$1,234,567.89`, заметка из 80 знаков, категория «Документы и курсы», имя второго человека из 20 знаков: ничего не вылезает за край, текст обрезается многоточием. Тест: Задача 15 (демо с такими данными + проверка `scrollWidth <= clientWidth` по всем экранам).
3. **Отмена удаления после синхронизации** — удалил трату, синхронизация прошла, нажал «Отменить» через 5 с: трата вернулась и на сервере (мягкое удаление этапа 1). Тест: Задача 4 (удалить → `scheduler.kick` → «Отменить» → строка живая, `deleted_at null`).
4. **Тема «Как в системе» и перезапуск** — выбранная тема переживает перезапуск, «Светлая» работает на тёмной системе, переключение без перезагрузки экрана. Тест: Задача 1.
5. **Долго без связи** — облачко показывает «ждёт отправки», записи создаются и редактируются офлайн, «потянуть вниз» без сети не зависает (короткая ошибка). Тест: Задача 6.
