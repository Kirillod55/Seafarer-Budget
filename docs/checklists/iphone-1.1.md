# Проверка на iPhone — Seafarer Budget 1.1 (этап 7)

Ручная проверка Кириллом на реальном iPhone (Safari → «На экран Домой»). Эмулятор не показывает вырез, клавиатуру и офлайн как есть.

- [ ] **Вырез и «＋».** Приложение открыто с иконки «Домой»: шапка и кнопка «＋» не под чёлкой / индикатором «Домой», ничего не обрезано сверху и снизу.
- [ ] **Клавиатура.** Открыть шторку записи, тапнуть поле суммы: клавиатура не закрывает поле суммы и кнопку сохранения.
- [ ] **Без зума.** Тап по любому полю ввода (шрифт 17 px): страница не увеличивается и не «прыгает».
- [ ] **Офлайн.** Включить авиарежим → приложение открывается, запись сохраняется на устройстве; выключить авиарежим → запись уходит на сервер (появляется у второго устройства / в боте).
- [ ] **Обновление версии не обрывает ввод.** Выпустить новую версию, открыть приложение, начать вводить запись (шторка открыта) — страница не перезагружается и введённое не пропадает; обновление применяется, когда приложение свернули или после закрытия шторки при следующем сворачивании.
- [ ] **Переход с 1.0 на 1.1.** После выпуска закрыть приложение из переключателя (смахнуть вверх) и открыть заново: открывается 1.1, записи и настройки на месте, синхронизация идёт.
- [ ] **Иконка.** На «Домой» — лайм с якорем. Старый значок удалить и добавить заново (iPhone кэширует иконку на момент добавления).
- [ ] **Потянуть вниз на главной.** Потянуть главную вниз — двигается только полоса синхронизации, страница не пружинит; стрелки крутятся, затем «Синхронизировано» и полоса сворачивается. В авиарежиме — короткая ошибка, ничего не зависает.
- [ ] **Прокрутка вверх с «дрожью».** Главная прокручена в самый верх; начать прокрутку вверх так, чтобы палец сперва чуть дрогнул вниз: страница всё равно прокручивается (жест не застревает в «потянуть для синхронизации»).
- [ ] **Список при открытой клавиатуре.** В шторке записи или в «Счета» открыть выбор счёта / валюты, когда клавиатура открыта: список целиком на экране (не уходит под клавиатуру и за верх), пункт выбирается.
