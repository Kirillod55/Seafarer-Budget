# Автообновление программы для Windows — ключи подписи

Делается **один раз на этапе 7** (выпуск 1.1.0). До этого в `src-tauri/tauri.conf.json` → `plugins.updater.pubkey` стоит заглушка `REPLACE_AT_RELEASE_STAGE7_WITH_TAURI_SIGNER_PUBLIC_KEY`: сборка с ней не сможет проверить обновление, поэтому выпускать без замены нельзя.

1. Создать пару ключей на своей машине (не в репозитории):
   `npx tauri signer generate -w %USERPROFILE%\.tauri\seafarer-budget.key`
   Команда спросит пароль и напечатает открытый ключ; рядом появится `seafarer-budget.key.pub`.
2. Открытый ключ (содержимое `.key.pub`, одной строкой) — в `tauri.conf.json` → `plugins.updater.pubkey`, коммит.
3. Закрытый ключ и пароль — только в секреты репозитория GitHub: `TAURI_SIGNING_PRIVATE_KEY` (содержимое файла `.key`) и `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`. В чат, в репозиторий, в `.env` — никогда. Файл ключа хранить в резервной копии: без него следующие версии не установятся поверх.
4. Сборка по тегу (`v1.1.0`) с этими секретами создаёт установщик, подпись `.sig` и `latest.json` (`bundle.createUpdaterArtifacts: true`); все три выкладываются в выпуск GitHub. Программа проверяет `https://github.com/Kirillod55/Seafarer-Budget/releases/latest/download/latest.json` при запуске и раз в 6 часов.
5. 1.1.0 ставится вручную последний раз; дальше — «Обновить и перезапустить» в уведомлении справа внизу или «Настройки → О программе → Проверить обновления».

Проверка на этапе 7: собрать 1.1.0, поставить; выпустить тестовый 1.1.1 → в 1.1.0 должно появиться уведомление, обновление ставится и программа перезапускается с теми же данными.
