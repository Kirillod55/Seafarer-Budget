# Seafarer Budget — как пользоваться

## Где что

- **iPhone:** https://kirillod55.github.io/Seafarer-Budget/ — открыть в Safari → «Поделиться» → «На экран Домой».
- **Windows:** установщик в [Releases](https://github.com/Kirillod55/Seafarer-Budget/releases) (`Seafarer-Budget-<версия>-setup.exe`). При первом запуске «Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».
- **Бот:** @SeafarersBudget_bot в Telegram. Отвечает только тебе.

Первый запуск на каждом новом устройстве нужен с интернетом (приложение сначала скачивает твои данные). Дальше работает и офлайн, а синхронизируется, когда появится связь.

## Как писать боту

| Пишешь | Получится |
|---|---|
| `кофе 80` | расход 80 ₴ (гривна по умолчанию) |
| `такси 15 eur`, `обед 12,50 €` | расход в евро |
| `продукты 250 лей` / `mdl` / `lei` | расход в леях |
| `$15 такси`, `15$ такси`, `бакс` | расход в долларах |
| `вчера кофе 80` | запись на вчерашний день |
| `зп 3000 usd` или `+3000 usd` | доход |
| `цель машина 500` / `цель машина -200` | отложить в цель / забрать из цели |

Если бот не узнал категорию, трата сразу сохраняется в «Прочее», а под ответом появляются кнопки — нажми нужную, и в следующий раз бот угадает сам.

Команды (или те же слова без слэша): `/today` (сегодня), `/month` (месяц), `/left` (остаток — сколько можно тратить), `/undo` (отмена последней записи), `/help`.

## Если что-то не так

- **Бот молчит или приложение пишет «офлайн» при интернете:** бесплатный проект Supabase засыпает после 7 дней без использования. Зайди на supabase.com → проект → **Restore project**. Данные не теряются.
- **На значке синхронизации «ошибка: …»:** запись, которую сервер не принял, отложена и не мешает остальным. Открой эту запись в приложении и сохрани заново, или перезапусти приложение.
- **Резервная копия:** «Ещё» → «Экспорт в CSV» — файл открывается в Excel.

## Обновление программы

Новая версия: поднять `version` в `package.json` и `src-tauri/tauri.conf.json`, закоммитить и отправить тег `v<версия>` — GitHub сам соберёт установщик в Releases. Приложение для iPhone обновляется само после каждой отправки в `main`.
